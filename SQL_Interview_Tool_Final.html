Technical Interview Tool — SQL Assessment

Interviewer Guide

Read this before starting. This tool gives you questions, data scripts, hints and scoring — all in one place. Keep this tab open throughout the interview.

Section 1 — Pre-Interview Checklist
📋
Ensure you have this tool open on your screen before the candidate joins. Do not share your screen — keep this visible only to you. (you can share the postgressql compatible functions if the candidate is stuck)
🔗
Open compiler links in separate browser tabs now:
SQL: https://onecompiler.com/postgresql
Python: https://onecompiler.com/python
💬
Have Microsoft Teams chat open with the candidate. You will paste the data setup code and compiler links via Teams chat.
📝
Go to Page 3 (Score Sheet) and fill in the candidate name, role and date before the interview starts.
🔍
Preview the questions on Page 2 and decide which questions you will ask. Copy the data code from Page 2 and have it ready to paste.
⚠️
Privacy ReminderNever share your screen with the candidate. They should only see what you deliberately paste into Teams chat.
Section 2 — Conducting the Interview
1️⃣
Always start with Easy SQL questions. This warms the candidate up and quickly gauges baseline competence. If they cannot answer Easy questions, politely conclude the interview — no need to continue.
2️⃣
Progress Easy → Medium → Hard within SQL, then repeat the same for Python. Do not skip levels or switch languages mid-way.
3️⃣
For each SQL question, copy the data code from Page 2 and paste it in Teams chat. Ask the candidate to run it in the compiler before writing their answer query.
4️⃣
Hints are allowed but reduce the score. Give syntax hint first, then logic hint only if still stuck. Never give hints on Easy questions.
5️⃣
Aim for at least 6 questions : 2 Easy + 3/4 Medium + 1/0 Hard.
🤝
Courtesy NoteIf concluding early due to poor performance, always thank the candidate sincerely and let them know the team will be in touch. Let HR handle feedback communication.
